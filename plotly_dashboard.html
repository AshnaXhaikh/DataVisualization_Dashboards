📊 Comparison & Ranking

📊 1. Bar Chart - Sales Performance by Region

🎯 Scenario: Comparing sales across different regions or categories
💡 Goal: Identify top-performing regions and rank performance
✅ DO: Sort bars for easy ranking, use consistent colors ❌ DON'T: Use too many categories (>12), start y-axis above zero

📊 2. Grouped Bar Chart - Quarterly Sales by Region

🎯 Scenario: Comparing multiple metrics across categories
💡 Goal: Analyze seasonal patterns and regional performance trends
✅ DO: Limit groups to 3-4, use clear legends ❌ DON'T: Overcrowd with too many groups, use similar colors

📈 Distribution & Frequency

📊 3. Histogram - Customer Spending Distribution

🎯 Scenario: Understanding data distribution and identifying patterns
💡 Goal: Detect skewness, outliers, and central tendency
✅ DO: Choose appropriate bin size, show normal curve overlay ❌ DON'T: Use too few or too many bins, hide outliers

📊 4. Box Plot - Salary Distribution by Department

🎯 Scenario: Comparing distributions and identifying outliers
💡 Goal: Detect median, quartiles, and anomalies across groups
✅ DO: Show outliers, add mean markers for context ❌ DON'T: Hide outliers, use for small datasets (<20 points)

📊 5. Violin Plot - Age Distribution by Customer Segment

🎯 Scenario: Visualizing full distribution with density information
💡 Goal: See both distribution shape and statistical summary
✅ DO: Combine with box plot inside, use for multimodal data ❌ DON'T: Use with very large datasets (>10k points)

📊 6. Density Contour Plot - Bivariate Distribution

🎯 Scenario: Understanding correlation and density between two variables
💡 Goal: Identify clusters, correlation patterns, and outliers
✅ DO: Use for large datasets, add marginal distributions ❌ DON'T: Use with sparse data, ignore color scale

🔄 Correlation & Relationships

📊 7. Scatter Plot - Marketing Spend vs Revenue

🎯 Scenario: Exploring relationships between two continuous variables
💡 Goal: Identify correlation strength, direction, and outliers
✅ DO: Add trend line, use transparency for overlapping points ❌ DON'T: Overplot without transparency, ignore outliers

📊 8. Bubble Chart - Market Analysis (3 Variables)

🎯 Scenario: Visualizing three dimensions of data simultaneously
💡 Goal: Show relationships between market share, growth, and size
✅ DO: Scale bubbles proportionally, use clear labels ❌ DON'T: Use too many bubbles, ignore color meaning

📊 9. Correlation Heatmap - Feature Relationships

🎯 Scenario: Visualizing correlation matrix for feature selection
💡 Goal: Identify multicollinearity and feature importance
✅ DO: Use diverging color scale, annotate values ❌ DON'T: Use too many features, ignore colorblind-friendly palettes

📉 Time Series & Trends

📊 10. Line Chart - Stock Price Trend

🎯 Scenario: Tracking changes over time and forecasting trends
💡 Goal: Identify patterns, seasonality, and long-term trends
✅ DO: Show confidence intervals, use consistent time scales ❌ DON'T: Connect missing data points, skip time periods

📊 11. Area Chart - Cumulative Revenue by Channel

🎯 Scenario: Showing cumulative trends and composition over time
💡 Goal: Compare contribution of different categories over time
✅ DO: Stack transparently, order categories logically ❌ DON'T: Use too many categories, hide baseline

🥧 Composition & Proportions

📊 12. Pie Chart - Market Share Distribution

🎯 Scenario: Showing parts of a whole with 2-5 categories
💡 Goal: Display proportion and relative size of segments
✅ DO: Limit to 5-6 slices, sort by size, use donut for multiple series ❌ DON'T: Use for many categories, 3D effects, small slices

📊 13. Sunburst Chart - Hierarchical Data Structure

🎯 Scenario: Visualizing multi-level hierarchical relationships
💡 Goal: Understand nested category proportions and structure
✅ DO: Limit depth to 3-4 levels, use interactive clicking ❌ DON'T: Use too many levels, ignore color hierarchy

🌍 Geospatial & Maps

📊 14. Choropleth Map - Global GDP Distribution

🎯 Scenario: Visualizing geographic patterns and regional variations
💡 Goal: Identify geographic clusters and regional disparities
✅ DO: Use appropriate color scale, include legend ❌ DON'T: Use divergent scales for one-directional data

📊 15. Scatter Map - Store Locations & Performance

🎯 Scenario: Displaying point-based geographic data
💡 Goal: Show spatial distribution and cluster patterns
✅ DO: Use cluster markers, add hover information ❌ DON'T: Overplot without clustering, ignore zoom levels

🚀 Advanced Analytics

📊 16. 3D Scatter Plot - Multi-dimensional Analysis

🎯 Scenario: Exploring relationships in 3+ dimensions
💡 Goal: Visualize clustering and patterns in high-dimensional space
✅ DO: Enable rotation, use color for 4th dimension ❌ DON'T: Use for categorical data without clear labeling

📊 17. Parallel Coordinates - Multidimensional Patterns

🎯 Scenario: Analyzing high-dimensional multivariate data
💡 Goal: Identify patterns across multiple variables simultaneously
✅ DO: Standardize axes, use brushing for selection ❌ DON'T: Use too many dimensions (>10), ignore color

📊 18. Waterfall Chart - Financial Bridge Analysis

🎯 Scenario: Showing cumulative effect of sequential changes
💡 Goal: Understand how initial value changes to final value
✅ DO: Color code positive/negative, show totals ❌ DON'T: Skip intermediate steps, hide connectors

📊 19. Funnel Chart - Conversion Analysis

🎯 Scenario: Analyzing conversion rates and drop-offs
💡 Goal: Identify bottlenecks in customer journey
✅ DO: Show conversion rates, use consistent stages ❌ DON'T: Skip stages, ignore drop-off reasons

📊 20. Gantt Chart - Project Timeline

🎯 Scenario: Visualizing project schedules and dependencies
💡 Goal: Track progress, identify critical path, manage resources
✅ DO: Show dependencies, highlight critical path ❌ DON'T: Overcrowd with tasks, hide milestones

📊 21. Radar Chart - Performance Metrics Comparison

🎯 Scenario: Comparing multiple metrics across entities
💡 Goal: Identify strengths and weaknesses across categories
✅ DO: Normalize scales, limit to 8-10 metrics ❌ DON'T: Use for ranking, compare too many entities

📊 22. Sankey Diagram - Flow Analysis

🎯 Scenario: Visualizing flows, migrations, and pathways
💡 Goal: Understand volume and direction of flows between stages
✅ DO: Use color coding, simplify complex flows ❌ DON'T: Overcomplicate with too many nodes
